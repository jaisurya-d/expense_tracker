## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 11 – Reports & Data Aggregation
### Concepts Covered

- Generating monthly and yearly expense reports

- Filtering data based on date ranges

- Implementing Python aggregation logic

- Summarizing expenses for better insights

- Displaying analytical data in templates

### Knowledge Gained

- By the end of Day 11, learners gained practical skills in analyzing and summarizing application data, enabling them to generate meaningful reports and insights from stored expense records.
