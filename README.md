## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 5 – CRUD Operations
Concepts Covered

- Create, Read, Update, Delete (CRUD) operations

- Displaying database records in templates

- Editing existing records using forms

- Deleting records securely

- Dynamic data rendering in Django templates

### Knowledge Gained

- By the end of Day 5, learners gained hands-on experience in managing database records dynamically, including creating new entries, viewing stored data, updating existing records, and deleting records using Django views and templates.
