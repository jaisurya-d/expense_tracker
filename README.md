## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 13 – Template Inheritance & Code Optimization
### Concepts Covered

- Creating and using base templates

- Template inheritance using {% extends %} and {% block %}

- Including reusable components with {% include %}

- Implementing a reusable navbar

- Applying the DRY (Don’t Repeat Yourself) principle

### Knowledge Gained

- By the end of Day 13, learners understood how to write clean, maintainable, and scalable Django applications by optimizing template structure and reusing common components efficiently.
