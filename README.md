## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 12 – Charts & Data Visualization
### Concepts Covered

- Integrating Chart.js with Django

- Creating pie charts and bar charts

- Passing dynamic data from Django views to JavaScript

- Visual representation of expense data

- Enhancing user insights through charts

### Knowledge Gained

- By the end of Day 12, learners learned how to visualize application data effectively using charts, making it easier to understand spending patterns and gain meaningful insights.
