## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 7 – Static Files (CSS & JS)
### Concepts Covered

- Configuring static files in Django

- Linking and managing static assets

- Custom CSS styling for improved UI

- JavaScript integration for basic interactivity

- Enhancing frontend behavior using static files

### Knowledge Gained

- By the end of Day 7, learners understood how to enhance application design and interactivity by effectively using static files such as CSS and JavaScript within a Django project.
