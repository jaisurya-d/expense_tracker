## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 10 – Categories & Relationships
### Concepts Covered

- Understanding relational database concepts

- Using ForeignKey relationships in Django models

- One-to-Many relationship mapping

- Linking expenses with categories

- Managing related data using Django ORM

### Knowledge Gained

- By the end of Day 10, learners learned how to design relational databases using Django ORM, effectively linking expenses with categories and managing related data in a structured manner.
