## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 6 – UI Improvements & Data Display
### Concepts Covered

- Using Bootstrap for responsive UI design

- Creating and styling Bootstrap tables

- Dynamic data rendering in templates

- Template loops (for) and conditional statements (if)

- Improving user experience through structured layouts

### Knowledge Gained

- By the end of Day 6, learners learned how to present data clearly and professionally by dynamically displaying database records using Bootstrap components and Django template logic.
