## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 8 – User Registration
### Concepts Covered

- Django built-in User model

- Creating a user registration form

- Password validation and security rules

- Using the Django messages framework

- Handling user feedback during registration

### Knowledge Gained

- By the end of Day 8, learners learned how user accounts are created securely in Django, including validating passwords, saving user data safely, and providing meaningful feedback to users during the registration process.
