## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 4 – Forms & User Input Handling
### Concepts Covered

- HTML forms and form structure

- Handling POST requests in Django

- CSRF protection for secure form submissions

- Saving form data to the database

- Basic form validation techniques

### Knowledge Gained

- By the end of Day 4, learners gained practical experience in collecting user input through forms, securely handling form submissions, validating data, and storing user-provided information in the database using Django best practices.
