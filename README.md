## Expense Tracker Project

This repository contains an Expense Tracker application built using Django.
The project is developed in a day-wise branch structure to clearly track learning progress and feature implementation.

## Day 9 – Authentication & Authorization
### Concepts Covered

- User login and logout functionality

- Session handling in Django

- Authentication workflows

- Using the login_required decorator to protect views

- Restricting access to authenticated users

### Knowledge Gained

- By the end of Day 9, learners understood how Django manages user sessions and implements access control, ensuring that only authenticated users can access protected parts of the application.
